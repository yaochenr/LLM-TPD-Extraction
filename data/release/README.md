# Released datasets

- `AutoTPD-MG.csv`: standardized AutoTPD records extracted from MolGlueDB source papers with PMC full text available.
- `AutoTPD-PROTAC.csv`: standardized AutoTPD records extracted from PROTAC-DB 3.0 source papers with PMC full text available.
- `AutoTPDplus-MG.csv`: AutoTPD-MG merged with MolGlueDB, with AutoTPD-covered papers represented by AutoTPD records.
- `AutoTPDplus-PROTAC.csv`: AutoTPD-PROTAC merged with PROTAC-DB 3.0, with AutoTPD-covered papers represented by AutoTPD records.
